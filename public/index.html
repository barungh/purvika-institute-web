Capstone project

Stock Trading Automation

Your final project is a working trading bot that you plan with AI, build with agents and run on your own server. It uses paper trading only, so no real money is at risk.

  1. Collect daily prices for NSE stocks into a database
  2. Write one clear trading rule and backtest it on a year of data
  3. Paper-trade it every market day, with Telegram alerts
  4. Publish a results page with HTTPS, monitoring and backups
